PresentAI  ·  how a deck gets made

From a one-line topic to a deck you can edit

1

Topic

You type what the deck is about, in one line.

Done by you
→
2

Outline

Six or more points, one per slide. You edit, drag and add points before going on.

Done by Gemini

3

Slides

Each point becomes a slide, written as layout data modelled on 8 built-in layouts.

Done by Gemini
→
4

Photos

Each image block's description is searched. The first landscape photo goes in.

Done by Pexels
→
5

Editor

Drag in blocks, reorder slides, pick one of 25 themes. Saves as you go.

Done by you
2 Gemini calls per deck: one for the outline, one for every slide at once.
